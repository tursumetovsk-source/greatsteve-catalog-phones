# Greatsteve — предварительная оценка iPhone из ломбарда

Отдельный сайт по утверждённому референсу: тёмный первый экран, два светлых шага анкеты, лаймовые кнопки. Основной каталог Greatsteve собирается и публикуется отдельно.

```sh
cd valuation
npm ci
npm test
npm run build
npm run dev
```

## Прайс и расчёт

В `src/catalog.json` — снимок 21 модели / 69 вариантов памяти от 01.10.2026, полученный чтением указанного пользователем кабинета Bauback. Использованы действующие настройки осмотра компании 1, а не коэффициенты старого публичного калькулятора. Данные клиентов, учётные записи и реквизиты доступа не экспортируются.

Формула повторяет `App\\Services\\InspectionConfig::evaluate`: проценты складываются, затем применяются к базовой цене; фиксированные поправки складываются отдельно; результат округляется и ограничивается снизу нулём. Тестовый набор `tests/bauback-oracle.json` получен вызовами работающего серверного калькулятора без записи в БД: 276 сочетаний модели, памяти и состояния.

Неизвестные ответы дают верхний ориентир при известных поправках. Отказные признаки переводят оценку на менеджера. Полное погашение вычитается из оценки; отрицательная разница не подменяется обещанием выплаты.

Прайс **не синхронизируется автоматически**. При изменении цен или правил нужно повторно выгрузить каталог и действующие настройки только чтением, обновить `catalog.json` и серверный тестовый набор, выполнить проверки и опубликовать новую версию. Пароли и SSH-доступ не нужны опубликованному сайту.

Убран служебный вариант экрана «ТЕСТ»; клиентские названия ремонта упрощены без изменения коэффициентов. Диапазон аккумулятора «95% и выше» закрывает пробел исходной подписи «Более 95%». В исходном прайсе iPhone 17 Air 1 ТБ дешевле 512 ГБ; значение подтверждено повторным чтением и сохранено без самостоятельного изменения.

## Заявка и аналитика

WhatsApp открывает черновик с моделью, памятью, ответами о состоянии, ломбардом/филиалом, полным погашением, датой, расчётом, номером заявки и источником. Клиент сам нажимает «Отправить». Direct: скопировать текст, открыть диалог и вставить. При отказе в доступе к буферу обмена доступен текст для ручного копирования.

Счётчик Метрики 109235626: `assessment_start`, `assessment_ready` (валидная заявка перед контактным действием), `whatsapp_click`, `direct_copy`, `direct_open`. Передаются только действие и проверенные UTM-метки. Состояние телефона, ломбард, сумма долга, расчёт и номер заявки в события не включаются. Вебвизор, карта кликов и автоматическое отслеживание ссылок выключены. Цели и отчёты в кабинете отдельно требуют настройки и проверки при доступе владельца.

Клик и скопированный текст не означают полученное обращение или завершённую сделку. Фактические заявки и выкупы администратор сопоставляет по номеру GS в сообщении.

## Публикация

Этот каталог привязан к отдельному Vercel-проекту `greatsteve-vykup`. Публикация из `valuation`: `vercel deploy --prod`. Не публиковать его в основной проект `greatsteve`.

Поддомен для подключения: `ocenka.greatsteve.kz`. DNS зоны Greatsteve обслуживает Cloudflare; записи добавляются там по текущей рекомендации Vercel. Автоматическая публикация из Git пока не подключена.

## Проверки интерфейса

Полный браузерный сценарий хранится в рабочей папке `outputs/greatsteve-pawn-buyout/browser-qa.cjs`: валидация, WhatsApp без реальной отправки, Direct/буфер обмена, ошибки аналитики, неизвестное состояние, отрицательная разница, смена модели и отсутствие горизонтальной обрезки на 320–1440 px.
